# 重设计（v4 · 科技极简）

## 用户反馈

v3（Console / 终端美学）元素过多：启动日志、`$` 提示符、`##` 标题前缀、LED 灯、扫描线、
粒子网络、荧光绿发光 —— 视觉噪音大，不够"极简"。本轮做**减法**。

## 方向：Tech Minimal

参考 Linear / Vercel / Stripe 一类的现代科技产品观感：几乎无装饰、靠排版与留白建立秩序、
单一低饱和强调色、动效只服务于理解而非炫技。

### 保留（真正有价值）
- 力导向知识图谱：内容关系可视化，是本站最有信息量的交互
- 命令面板 ⌘K：键盘优先的导航
- 滚动揭示：温和的位移淡入
- 滚动进度：细线

### 删除（视觉噪音）
- 终端启动日志、`$`/`~/` 提示符、`[ ]` 方括号
- 标题的 `##` / `###` 前缀、引用的 `>` 前缀
- LED 呼吸灯、闪烁光标、打字机
- 卡片扫描线、粒子网络背景
- 荧光绿发光、CRT 扫描线、网格底纹、角标装饰
- 荧光黄/品红等多色信号色

### 视觉规范
- **底色**：近黑 `#0A0A0B`（深色默认）/ 纯白（日间）
- **层次**：仅两级灰阶表面，靠 1px hairline 分隔，不用色块
- **强调**：单一低饱和蓝 `#4C8DFF`（不是荧光绿），仅用于链接、选中、图谱主节点
- **文字**：`-apple-system`/Inter 无衬线主导，等宽仅用于数据/日期/编号
- **字号**：正文 15-16px，行高 1.7；标题用克制阶梯，不追求巨大
- **留白**：区块间距 96-128px，内容区 1120px
- **圆角**：4-6px，克制
- **动效**：只保留 opacity/transform，时长 150-300ms，无弹跳无循环动画

### 页面节奏（极简站靠分区呼吸）
1. 首屏：大字姓名 + 一句话 + 两个动作 + 一行数据，下方一条 hairline
2. 图谱区：全宽，无边框面板，只有顶部一行说明
3. 项目区：3 列网格，纯图 + 文字，hover 仅位移 2px
4. 时间线：左轴细线，条目间 hairline 分隔

## 验收
- 无循环动画、无拟物装饰、无发光
- 强调色占比 < 3%
- 桌面/移动端无横向溢出
- 知识图谱与 ⌘K 仍可用
