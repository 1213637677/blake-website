# 重设计调研与方案（v2）

## 1. 调研：优秀个人站做对了什么

参考方向：Site Builder Report / Awwwards 的个人站收录、瑞士编辑排版复兴、brutalist 与 anti-design 回潮、以及一批工程师站的"工作室感"实践。抽出来的共性：

| 观察 | 说明 |
| --- | --- |
| **排版即个性** | 优秀站几乎都有一个强字体主张：超大衬线标题、衬线/无衬线/等宽三族混排、非对称字重。不是"标题加粗一点"。 |
| **反模板脸** | 明确拒绝"英雄区 + 三卡片 + 渐变按钮"的 SaaS 骨架。首屏往往是纯排版构图，不放卡片。 |
| **有人的痕迹** | 手写批注、涂鸦、胶带、照片、噪点。质感层让页面"像一个人做的"，而不是设计系统生成的。 |
| **编辑式布局** | 杂志分栏、旁注、错位、出血。栅格用来打破而不是用来对齐。 |
| **微交互是记忆点** | 自定义光标、滚动揭示、hover 形变、跟随进度。静态站现在显得廉价。 |
| **真实媒体** | 项目有图、有截图。纯文字卡片堆是"死板"的最大来源。 |
| **强对比而非低对比** | 要么纯白 + 近黑 + 一个高饱和强调色，要么深色工作室。中间调的"低饱和高级灰"反而最容易沦为模板脸。 |

## 2. 本站的病因（对症下药）

| 症状 | 病根 |
| --- | --- |
| 看起来像模板 | 所有页面同构：eyebrow + 标题 + 等宽列表行。结构重复到没有意外。 |
| 没有性格 | 纸白 + 墨绿是"安全"配色，克制到没有态度。 |
| 死板 | 12 栏对称栅格，清一色 1px 描边圆角卡片，间距完全均匀。 |
| 没有图像 | 全是文字块，项目卡没有视觉锚点。 |
| 静态 | 零滚动反馈、零 hover 惊喜、零光标交互。 |

## 3. 设计概念：**Studio Notebook（工作室手稿）**

一间开着灯的深夜工作室：桌上是摊开的手稿、贴着胶带的剪报、荧光笔划过的段落、摊着的项目草图。

### 视觉支柱

1. **三族字体对撞**
   - 超大标题：衬线（Georgia + 中文宋体回退），只在 h1/h2/数字上用
   - 正文：无衬线（Inter + PingFang）
   - 元信息：等宽 + 大写字距
   - 中文宋体做大标题是与满街 PingFang 黑体最直接的区别
2. **质感层**：全局 SVG 噪点（feTurbulence，内联 data-uri，零请求），浅色是纸纹、深色是暗噪。这是治愈"死板/塑料感"最便宜的一招。
3. **非对称与错位**：项目卡轻微随机旋转、胶带标签、偏移硬阴影（不是模糊投影）。栅格用来打破。
4. **高对比配色**
   - 浅色：纯白 `#FFFFFF` + 近黑 `#0A0A0A` + 朱红 `#E23E29` + 荧光黄 `#F5C518`（marker）
   - 深色：近黑 `#0C0C0D` + 冷白 `#F2F2F0` + 亮朱红 `#FF5A3C` + 荧光黄 `#FFD54A`
   - 荧光黄只用于"标注/高亮"，模拟荧光笔
5. **打破首屏**：不放卡片。全宽排版构图 —— 超大衬线姓名、错位的一句话、一道朱红竖线的 NOW 块、底部滚动 ticker。
6. **时间线重构**：从等宽行列表改成**中轴叙事流**，节点按重要性有大小差异，卡片错落 + 轻旋转 + hover 归正浮起，配跟随滚动的进度轴。
7. **程序化封面**：项目无图时生成几何封面（首字母 + 渐变 + 噪点），消灭纯色块。
8. **微交互**
   - 自定义光标（桌面端，十字准星 + hover 放大）
   - 链接 hover：荧光黄 marker 由左向右划过
   - 滚动揭示：IntersectionObserver 淡入 + 位移
   - `prefers-reduced-motion` 全部关闭

### 明确的取舍

- 不做：渐变 orbs、orb 光斑、玻璃拟态、装饰性 SVG 插画 hero、营销式分栏。
- 保留：内容模型、后台、路由、搜索、RSS —— 只换皮与骨架，不换数据。
- 字体仍不引第三方 CDN（国内加载慢），用系统衬线栈。

## 4. 验收

- `npm run build` 通过
- 首屏在无图片的前提下仍有视觉重量（排版 + 质感 + 程序化封面）
- 桌面/移动端无横向溢出
- 深浅两模式都成立
- 后台功能不回退
