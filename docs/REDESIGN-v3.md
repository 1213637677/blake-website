# 重设计调研与方案（v3 · 科技 / 动态交互）

## 1. 用户反馈与转向

v2（Studio Notebook）解决了"死板"，但方向偏编辑/手作，与"科技感 + 动态交互展示内容"的诉求不符。本轮转向：**Terminal / 控制台美学 + 数据驱动的动态交互**。

## 2. 调研：科技类个人站的做法

| 做法 | 说明 | 采用 |
| --- | --- | --- |
| 知识图谱 / 力导向图导航 | 节点=内容，连线=关系（共享标签、同项目）。把"浏览"变成"探索"，是科技站最有辨识度的交互 | ✅ 核心 |
| Canvas 粒子网络背景 | 鼠标连线、呼吸感粒子 | ✅ 首屏背景 |
| 终端 / monospace 美学 | 等宽字体主导、`>` 提示符、代码块质感、命令面板 | ✅ 视觉基调 |
| 打字机 / 流式文本 | 首屏文字逐字输出，模拟启动日志 | ✅ |
| 实时数据面板 | 统计数字滚动、状态灯、时钟、构建信息 | ✅ |
| 命令面板（⌘K） | 键盘优先的导航 | ✅ |
| 滚动驱动的形变动画 | GSAP ScrollTrigger 类：元素随滚动位移/缩放/淡出 | ⚠️ 用轻量 IntersectionObserver + CSS 变量实现，不引 GSAP |
| 数字滚动计数 | 统计值从 0 滚到目标 | ✅ |
| 3D / WebGL（Three.js） | 视觉冲击最强，但对内容站是负担 | ❌ 不上（内容可读性优先） |

## 3. 设计概念：**Console（控制台）**

把个人站做成一台"运行中的系统"：看得见的数据流、可以拖的知识网络、键盘优先的操作。

### 视觉
- 纯黑底 `#050506` + 单色荧光绿 `#00E599`（主）+ 青 `#22D3EE` + 琥珀 `#FFB020` + 品红 `#FF3E88`
- 等宽字体主导（JetBrains Mono 栈），中文回退到系统 sans
- 网格线 / 扫描线 / 十字准星 / 角标（corner brackets）作为装饰语言
- 发光（text-shadow / box-shadow）代替投影，模拟 CRT
- 深色为默认；浅色模式保留为"日间模式"（荧光绿→深墨绿）

### 动态交互（核心）
1. **粒子网络画布**：首屏背景，粒子随鼠标连线，密度自适应，移动端降采样
2. **打字机启动序列**：首屏标题逐字输出 + 光标闪烁
3. **力导向知识图谱**：首页核心区。节点=文章/项目/笔记/标签，连线=共享标签；可拖拽、可缩放、hover 高亮邻居、点击跳转。Canvas 实现，自写物理（不引 d3-force）
4. **数字滚动计数器**：统计值从 0 滚到目标
5. **命令面板 ⌘K**：键盘搜索跳转
6. **滚动驱动揭示**：位移 + 缩放 + 淡入
7. **实时状态条**：时钟、内容计数、构建时间
8. **hover 发光与扫描线**：卡片 hover 出现扫描动画

### 明确取舍
- 不上 Three.js / GSAP：自写 canvas 与 CSS 动画，保持体积与可读性
- 内容可读性优先：正文区不加任何动效干扰
- `prefers-reduced-motion` 全部降级为静态
- 保留：内容模型、后台、路由、RSS、搜索

## 4. 验收
- build 通过；图谱在数据为空时不报错
- 桌面/移动端无横向溢出；移动端禁图谱交互（降级为列表）
- 深色为默认且完整
- 键盘可达（⌘K、Tab 焦点可见）
